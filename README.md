# TaskSnap

中文名称：多任务并行备忘录

TaskSnap 是一个运行在 macOS 桌面上的浮动备忘录。它面向同时让 AI 执行多个任务的人：把当前任务的截图拖进窗口，截图会立刻变成一条任务；完成后点一下圆圈划掉即可。

## 核心体验

- 浮动在桌面上，始终像一张轻量任务便签。
- 支持把截图或图片文件拖入窗口生成任务，也可以按 Command-V 直接粘贴剪贴板图片。
- 支持在顶部菜单的设置窗口里配置 OpenAI-compatible 视觉大模型，配置保存前会测试可用性；必须先配置可用模型，才能添加截图任务。
- 任务列表直接展示截图缩略图，减少“这件事是什么来着”的回忆成本。
- 截图可以点击放大查看，每张任务卡片会使用不同的随机浅色背景。
- 已完成任务可以一键划掉，也可以批量清空。
- 本地 JSON 持久化，不依赖账号或云服务。

## 为什么做这个

AI 让单个人同时推进多个任务变得现实，但人的短期记忆没有跟着升级。TaskSnap 把“当前上下文”保存成可视任务卡片，让你在多个 AI 会话、网页、代码窗口、文档之间切换时，仍然知道每件事停在哪里。

## 开发运行

```bash
swift run TaskSnap
```

运行要求：

- macOS 14 或更新版本
- Swift 6.1 或更新版本

## 计划功能

- 全局快捷键快速显示/隐藏窗口
- 自动识别截图里的窗口标题或网页标题
- 按项目分组任务
- 任务完成归档与搜索
